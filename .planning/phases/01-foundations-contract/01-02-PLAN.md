<interfaces>
Field shape of PalmReading v1 (snake_case JSON keys; every key required; nullable where noted):

- `schema_version`: literal 1
- `reading_id`: UUID string
- `hand_side`: "left" | "right"
- `meta`: { `model`: str, `prompt_version`: str, `generated_at`: RFC 3339 UTC datetime, `locale`: str (BCP-47, e.g. "en", "hi") }
- `image_size`: { `w`: int > 0, `h`: int > 0 } (size of the image sent to the model)
- `verdict`: { `ok`: bool, `reason`: one of the 7 codes or null }
- `lines`: list of { `type`: heart|head|life|fate|sun, `label`: non-empty str, `present`: bool, `trace`: list of [x, y] (each 0..1), `trace_source`: llm|template|none, `interpretation`: str }
- `palm`: { `summary`: str, `traits`: list[str] } or null
- `love`: { `how_you_love`: str, `ideal_partner`: str, `challenges`: str } or null
- `career`: { `strengths`: str, `challenges`: str, `ideal_industries`: list[str] } or null

Kotlin names (package app.palm.contract): `PalmReadingDto`, `MetaDto`, `ImageSizeDto`, `VerdictDto`, `PalmLineDto`, `PalmSummaryDto`, `LoveDto`, `CareerDto`; enums `HandSide`, `LineType`, `TraceSource`, `InvalidReason` with `@SerialName` values equal to the JSON strings; `trace: List<List<Double>>`; nullable `reason`, `palm`, `love`, `career` with no default values (so a missing key fails a strict decode).
</interfaces>
</context>
