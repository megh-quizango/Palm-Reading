## Phase Goal

ROADMAP Phase 1 goal (verbatim): The project builds, installs and runs on the physical phone with the Nocturne theme, the phone can reach the local backend, and client and server share one frozen, versioned palm-reading contract.

Note (MVP mode): the Goal line is not a user story and none was invented; see 01-01-PLAN.md.

<objective>
Make the backend link diagnosable on the phone and keep the secret safe (FND-04, D-02, D-11): the status chip names why the backend is unreachable, shows the base URL and recovers with Retry; `/healthz` reports whether the Anthropic key is configured without ever revealing it; the device-detection edges of the one-command install are tested; the dev commands are documented.

Purpose: `adb reverse` rules vanish on reconnects (Pitfall 10); the developer must see the cause on the phone instead of reading Logcat. The repo is public, so key handling must be correct before Phase 2 adds a key.
Output: chip diagnosis, Settings + key reporting, tests on both sides, README.
</objective>
