## Phase Goal

ROADMAP Phase 1 goal (verbatim): The project builds, installs and runs on the physical phone with the Nocturne theme, the phone can reach the local backend, and client and server share one frozen, versioned palm-reading contract.

Note (MVP mode): the Goal line is not a user story and none was invented; see 01-01-PLAN.md.

Purpose: success criterion 2 forbids hand-copied token values; every later screen inherits this theme.

## Scope note: font assets (files_modified = 26)

The count is above the 15-file guideline on purpose. 14 of the 26 entries are binary or licence assets that one script writes: the 10 TTFs and 4 OFL texts in Task 2 are outputs of `tools/fonts.sh`, never edited by hand and checked as a set by `bash tools/fonts.sh --verify`. They cost the executor one script run, not 14 edits. The code work is the other 12 files across 2 tasks (Task 1: 10, two of them generator output; Task 2: fonts.sh and NocturneFonts.kt plus two files Task 1 already touched), which is inside the per-plan budget. Moving font generation into its own plan was weighed and rejected: Task 2's on-phone check (11 styles with Hindi lines) needs the fonts and the NocturneFonts wiring in the same build, so a separate plan would add a wave and a phone round trip without reducing the work.
