## Phase Goal

ROADMAP Phase 2 goal (verbatim): A local backend turns a palm photo, hand side and hand landmarks into a validated, safe, cached Palm / Love / Career reading through an async job API, proven on real palm photos before any client wiring.

Note (MVP mode): the Goal line is not in user-story format and no story was invented.

<assumption_delta_decision>
Detector signal: "pluralization" on the phrase "without a second model call" in the roadmap success criteria. That phrase means a repeated call, not a second case of an identity. The identity question it brushes against is real, though: the cache key. Primary noun: the install (X-Install-Id). Decision: no-change to the amended D-12, which already promoted the install id into the cache key so one install never receives another install's reading. Optional invariant test adopted in Task 2: a cache entry written for one install is never served to another.
</assumption_delta_decision>

<objective>
A re-scan of the same palm returns the identical reading without a model call (READ-04, D-12), an obviously unusable photo is answered without a model call (D-09), and a client over its rate limit or a tripped daily spend cap gets a clean busy instead of a model call (READ-10, D-14).

Purpose: determinism comes from the cache (sampling parameters are not available on these models), and the spend cap is the budget guard for a free, ad-funded app.
Output: dHash and blur metrics, cache, pre-gate, rate windows, spend ledger, tests.
</objective>
