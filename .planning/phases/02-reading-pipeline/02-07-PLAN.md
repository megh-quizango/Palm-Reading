## Phase Goal

ROADMAP Phase 2 goal (verbatim): A local backend turns a palm photo, hand side and hand landmarks into a validated, safe, cached Palm / Love / Career reading through an async job API, proven on real palm photos before any client wiring.

Note (MVP mode): the Goal line is not in user-story format and no story was invented.

<objective>
The eval harness that will prove the pipeline on real palm photos exists and runs green in fake mode (D-15): it measures latency, cost, line validity, repeat agreement, refusals and red-team behaviour, so plan 02-08 only has to supply the photos and the key.

Purpose: the model bake-off (D-06), the template-first answer (D-11), the pre-gate (D-09) and dHash (D-12) thresholds and the image red-team (D-13) are all decided from this harness's numbers.
Output: run_eval.py, make_landmarks.py, redteam.py, labels format, smoke test.

Created here:
- Eval defaults are anchored on the module, never on the cwd: `EVALS = Path(__file__).resolve().parent` (backend/evals) and `REPO = EVALS.parents[1]`.
- `python -m evals.run_eval` (cwd backend via `uv run --directory backend`), `main(argv: list[str] | None = None, settings: Settings | None = None) -> int`, following the `create_app(settings=None)` pattern: `s = settings or Settings()` is built inside main (never at import) and is the one object used for both the key check and the `--models` default. `parse_args(argv) -> argparse.Namespace`. Flags: `--fake`, `--synthetic`, `--models a,b` (default None, which main replaces with s.palm_model), `--locales a,b` (default en), `--repeats N` (1; 0 together with --redteam runs the red-team only), `--limit N`, `--concurrency N` (4), `--max-usd X` (8.0), `--redteam`, `--redteam-limit N` (2), `--photos DIR` (default EVALS/"photos"), `--out DIR` (default EVALS/"results"). Exit codes: 0 ok, 1 red-team leak or failed red-team cell, 2 refused (key missing, ignore gate).
- `ignored(path: Path) -> bool`: True for a path outside REPO (tmp dirs in tests); otherwise runs `git check-ignore -q <path relative to REPO, POSIX form>/.probe` with cwd=REPO, one path per call, and returns exit code == 0.
- Photo set layout (user-supplied, git-ignored): `<photos>/*.jpg` (also .jpeg/.png/.webp), `<photos>/labels.csv` with columns `file,hand_side,expected_ok,expected_reason,group,notes` (`group` = same physical hand across re-captures), optional `<stem>.landmarks.json` (21 [x, y, z] or null). Locale is a run parameter (`--locales`), not a label column.
- `python -m evals.make_landmarks` with `--model` (default EVALS/"models"/"hand_landmarker.task") and `--photos` (default EVALS/"photos"), run as `uv run --directory backend --with mediapipe==1.2.3 python -m evals.make_landmarks --model evals/models/hand_landmarker.task`.
