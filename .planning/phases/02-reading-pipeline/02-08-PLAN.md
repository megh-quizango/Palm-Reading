## Phase Goal

ROADMAP Phase 2 goal (verbatim): A local backend turns a palm photo, hand side and hand landmarks into a validated, safe, cached Palm / Love / Career reading through an async job API, proven on real palm photos before any client wiring.

Note (MVP mode): the Goal line is not in user-story format and no story was invented.

<objective>
Prove the pipeline on real palm photos with the real Claude API (the only plan that calls it, D-16): run the bake-off (D-06), measure line validity for the template-first question (D-11), calibrate the pre-gate (D-09) and dHash (D-12) thresholds, and run the image red-team (D-13). Output the eval summary the user signs off on in plan 02-09.

Purpose: the model is a cost/latency trade that Phase 6's p50 < 12 s / p95 < 30 s target and the spend cap depend on; it must be decided on measurements, not guesses.
Output: 02-EVAL.md (committed, aggregates only); per-call results stay in the git-ignored results dir.
</objective>
