## Phase Goal

ROADMAP Phase 3 goal (verbatim): A user can open the app, onboard once, land on a Home hub over the animated cosmic background, and pick which hand to scan, with everything persisted across restarts.

Note (MVP mode): the Goal line is not in user-story format and no story was invented. Run `/gsd-mvp-phase 3` if a user-story framing is wanted.

Note (tracer-first): this plan is the phase tracer. Splash -> Language -> Home is wired through every client layer (Activity + splash, activity-scoped ViewModel, DataStore, Navigation 3 stack, per-app locale, Compose screens, the root sky) and proven on the Redmi, including a true process restart. Plans 03-03 (Intro, Name, Birth) and 03-04 (Home hub, hand choice) expand from this spine in wave 2; 03-02 (sky, type scale, art) runs beside this plan in wave 1.

<objective>
First run: the user sees the branded system splash, picks English or Hindi (the UI switches at once), continues to Home, and after a kill and relaunch goes straight to Home in that language (ONB-01, ONB-02, ONB-06, HOME-01 greeting; D-01, D-02, D-04, D-06, D-11, D-18).

Purpose: prove the client architecture end to end on the phone before any expansion builds on it, and lay down the exact interfaces (routes, profile repository, test fakes, device tools) the wave-2 plans consume.
Output: dependency set (after consent), AppCompat + splash activity, profile repository, routes, nav host with the root sky, Language and minimal Home screens, en/hi strings, unit and instrumented tests, tools/ui.sh, tools/device-lock.sh.
</objective>
