## Phase Goal

ROADMAP Phase 3 goal (verbatim): A user can open the app, onboard once, land on a Home hub over the animated cosmic background, and pick which hand to scan, with everything persisted across restarts.

Note (MVP mode): the Goal line is not in user-story format and no story was invented. Run `/gsd-mvp-phase 3` if a user-story framing is wanted.

Note (wave 1, parallel with 03-01): this plan owns the Nocturne visual layer the wave-2 screens consume: the six-layer sky (FND-03), the Phase 3 type scale and every shared drawable. It never touches the phone, because 03-01 holds it in wave 1. The on-device half of its tracer runs as early as the phone allows: check-motion off/on on the debug build in 03-04 Task 1 (the first wave-2 task, before any hub screen is built on the sky), then battery saver, frame pacing and the release build in 03-05 Task 2. NocturneSkyTest covers only the pure timing helpers and rest-state constants; the "no clock, static" claim is proven by those device checks.

<objective>
The cosmic background becomes the six-layer animated star field from Figma "5 · Motion" (as recorded in 03-UI-SPEC.md "Background (FND-03)"), static under reduce motion, battery saver or a root pause (D-14); the type scale drops to the Phase 3 set and covers every Material 3 slot (D-07 Devanagari rules); and the 20 vector drawables the Intro, Home and hand-selection screens need exist under their final names (D-08, D-12, D-15 art).

Purpose: wave-2 plans 03-03 and 03-04 build their screens on these files without editing them.
Output: extended NocturneBackground, NocturneTheme changes, regenerated tokens, NocturneSkyTest, 20 drawables.
</objective>
