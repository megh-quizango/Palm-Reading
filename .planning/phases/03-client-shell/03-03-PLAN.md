## Phase Goal

ROADMAP Phase 3 goal (verbatim): A user can open the app, onboard once, land on a Home hub over the animated cosmic background, and pick which hand to scan, with everything persisted across restarts.

Note (MVP mode): the Goal line is not in user-story format and no story was invented. Run `/gsd-mvp-phase 3` if a user-story framing is wanted.

Note (wave 2): this plan expands the 03-01 tracer by inserting the Intro, Name and Birth steps between Language and Home. It touches only the onboarding package, two new components and its own strings file, so it runs beside 03-04. Both plans share the phone through tools/device-lock.sh.

<objective>

Purpose: completes the first-run journey of ROADMAP Phase 3 criterion 1.
Output: Intro, Name and Birth screens with ViewModels and pure rules, NocturneTextField / NocturneSelectField / NocturneChoiceTile, strings_onboarding.xml (en, hi), unit tests and OnboardingFlowTest.
</objective>
