## Phase Goal

ROADMAP Phase 4 goal (verbatim): The user points the phone at a palm, gets stable live guidance, and captures or imports a photo that is processed and ready to upload, running smoothly on the reference low-end phone.

Note (MVP mode): the Goal line is not in user-story format and no story was invented. Run `/gsd-mvp-phase 4` if a user-story framing is wanted.

Note (tracer-first): this plan is the phase tracer. One path, permission granted -> live preview -> raw MediaPipe palm/no-palm chip -> capture -> processed JPEG (upright, cropped, <= 1280 px, no EXIF) + 21 landmarks on the ScanReady placeholder, is wired through every layer this phase touches (manifest and Gradle, Nav3 route, permission, CameraX, MediaPipe LIVE_STREAM and IMAGE, decode/crop/encode, the cacheDir handoff, Compose) and proven on a physical phone before any expansion. The gallery picker is wired into the same pipeline only so that the wave-2 plans share a fixed `onGallery` interface. Inside this plan, Task 2 is the tracer (verified end to end on the phone first) and Task 3 expands it with the scanner's gallery button, the rejection dialog, the EXIF-free proof script and the updated Phase 3 HandSelectTest. Wave 2 expands from it in parallel: 04-02 (guidance quality and capture controls), 04-03 (every permission and camera fallback state), 04-04 (decode hardening, gallery rejections, processing UX). 04-05 calibrates on the phone and runs the phase gates.

Note (D-17): Task 1 is the only download consent of the phase. Plans 04-02..04-05 add no Gradle artifact and download nothing.

<objective>
A user on HandSelect taps Continue, allows the camera, sees the live back-camera preview with a palm/no-palm chip, captures their palm and lands on a ScanReady placeholder that shows the processed photo with its 21 landmarks (SCAN-02 tracer path, SCAN-03 raw state, SCAN-04 capture-when-palm, SCAN-05 picker wiring, SCAN-06 processing on API 28+, SCAN-07 throttle and pause; D-01..D-06, D-10..D-14, D-17).

Purpose: prove the camera + MediaPipe + processing architecture end to end on the phone, and freeze the interfaces the three parallel wave-2 plans build on.
Output: consented dependency set and model asset, the Scan route with ScannerContent, LiveHandTracker, MediaPipeHandDetector, AndroidPhotoProcessor, ScanResultHolder, ScanReady, NocturneStateBlock, NocturneDialog, tools/scan-open.sh and tools/check-capture.sh.
</objective>
