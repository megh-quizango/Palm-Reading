## Phase Goal

ROADMAP Phase 4 goal (verbatim): The user points the phone at a palm, gets stable live guidance, and captures or imports a photo that is processed and ready to upload, running smoothly on the reference low-end phone.

Note (MVP mode): the Goal line is not in user-story format and no story was invented. Run `/gsd-mvp-phase 4` if a user-story framing is wanted.

Note (scope): 22 files_modified entries across 3 tasks of 6-9 files each (four are generated test photos), accepted: each task is one concern with its own verify.

Note (D-16 HEIC): the HEIC instrumented case writes its HEIC with androidx.heifwriter (androidTest only), which the 04-01 consent lists. heifwriter 1.2.0 declares minSdk 29; 04-01 Task 2's android/app/src/androidTest/AndroidManifest.xml overrides that for the test APK only, so heicImport must check SDK_INT >= 29 before touching any HeifWriter class. It still exercises the API 28+ ImageDecoder path D-16 names; on an API 28 phone the required manual HEIC import in 04-05 Task 2 is the proof. If the user dropped heifwriter there, Task 1 leaves the HEIC case out, the 04-01 summary records it as the user's D-16 choice, and 04-05 Task 2's HEIC import check is required.

Note (wave 2): runs beside 04-02 and 04-03 on disjoint files. It owns the processing pipeline, the handoff and the screens around it (ScanScreen, ScanViewModel, ScanReady, ProcessingOverlay). The camera and live-guidance files belong to 04-02, the permission gate to 04-03.

<objective>
Make every photo that enters the app (camera or gallery, any Android version from 26, any size, any orientation) come out upright, cropped, <= 1280 px and EXIF-free with its 21 landmarks, reject bad photos clearly, and give processing and ScanReady their loading, cancel and empty states (SCAN-05, SCAN-06; D-10, D-11, D-12, D-16).

Purpose: ROADMAP Phase 4 success criterion 4.
Output: hardened AndroidPhotoProcessor with instrumented proof, crop/EXIF maths tests, processing UX, ScanReady states, cleanup at app start, the photo-picker backport entry.
</objective>
