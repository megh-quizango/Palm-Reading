## Phase Goal

ROADMAP Phase 4 goal (verbatim): The user points the phone at a palm, gets stable live guidance, and captures or imports a photo that is processed and ready to upload, running smoothly on the reference low-end phone.

Note (MVP mode): the Goal line is not in user-story format and no story was invented. Run `/gsd-mvp-phase 4` if a user-story framing is wanted.

Note (wave 3): the phase gate and the calibration. It is the only plan in its wave and owns the phone. Every phone command still runs inside tools/device-lock.sh. MIUI rules from Phase 3 apply: update installs only (never uninstall), keep test APKs installed, MIUIOP 10021 (background pop-up) set to Allow by the user before instrumented runs, wireless adb preferred, restore every changed setting.

<objective>
Calibrate the guidance on the real phone with the user's own hands, prove the scan session is smooth and cool on the reference low-end phone, run every on-device check the earlier plans could not, and close the deferred Phase 3 hardware gates in the same session (SCAN-02..SCAN-07; D-09, D-13, D-14, D-15).

Purpose: ROADMAP Phase 4 success criteria 2 (real hands) and 5 (2-minute session), plus the on-device halves of criteria 1, 3 and 4.
Output: debug HUD and recorder, tools/check-scan-session.sh, calibrated GuidanceConfig, recorded fixtures (local, or committed with consent), session, 16 KB and Phase 3 gate numbers in the summary and STATE.md.
</objective>
