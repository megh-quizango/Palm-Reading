## Phase Goal

ROADMAP Phase 5 goal (verbatim): The user sees a believable Palm / Love / Career reading with the detected lines drawn over their own photo, saved on the device and shareable, built and verified against fixture data before the real backend is wired.

Note (MVP mode): the Goal line is not in user-story format and no story was invented. Run `/gsd-mvp-phase 5` if a user-story framing is wanted.

Note (tracer): Task 1 is the tracer the orchestrator asked for: ScanReady "Read my palm" -> fixture reading for the processed photo -> saved in Room with the photo in filesDir -> Result with the lines over the user's own photo -> Back lands on Home, verified on emulator-5554. The emulator camera has no hand (04-05-SUMMARY), so the tracer reaches ScanReady through a minimal debug Fixture lab (D-05). Home's "Your last reading" card is a second read path over the same Room row and photo file, so it is the Task 3 expansion, which proves the kill + reopen on the emulator before the plan ends. Every wave-2 plan expands from the slice this plan proves.

Note (downloads): no new Maven artifact in this phase (RESEARCH Package Legitimacy Audit: none; FileProvider is in androidx.core, Room 3, Compose and kotlinx.serialization are present), so the D-25 consent checkpoint is not needed and `android/gradle/libs.versions.toml` stays unchanged.

Note (device): everything here runs on the x86_64 API 35 emulator `emulator-5554`; every device command sets `ADB_SERIAL=emulator-5554` so a connected phone is never used. Nothing is installed on the phone.

<objective>
Prove the whole Phase 5 slice end-to-end on the emulator: a lab photo on ScanReady becomes a stamped fixture reading, is saved (Room row + photo in filesDir) and opens on a Result screen with the lines drawn over the photo, a legend and the disclaimer (RES-02, RES-04, RES-05, RES-07; D-01, D-02, D-03, D-05, D-07, D-09, D-10, D-11, D-12, D-13, D-16, D-17, D-18, D-20, D-23, D-25). Then harden the store test-first (UUID file names, canonical paths, insert-failure cleanup, delete, v1 -> v2 open) and add the shared fakes and seeding helper the wave-2 plans use. Then add the Home "Your last reading" card that reopens the reading after the app is killed (HOME-03, RES-05; D-19).

Purpose: ROADMAP Phase 5 success criteria 1 (lines over the user's own photo, partial), 2 (disclaimer), 4 (saved, survives kill, Home reopens) and 5 (Scan again, Ask [Guide]).
Output: the reading seam, store, DB v2, Result route and screen, PalmPhoto overlay, Home last-reading card, the minimal Fixture lab, tools/result-open.sh, tests and fakes.
</objective>
