## Phase Goal

ROADMAP Phase 5 goal (verbatim): The user sees a believable Palm / Love / Career reading with the detected lines drawn over their own photo, saved on the device and shareable, built and verified against fixture data before the real backend is wired.

Note (MVP mode): the Goal line is not in user-story format and no story was invented.

Note (gate): everything runs on emulator-5554 with `ADB_SERIAL=emulator-5554`; nothing is installed on the phone. `workflow.human_verify_mode` is end-of-phase, so the visual sign-off is a `<human-check>` collected by `/gsd-verify-work`, not a blocking checkpoint. Screenshots go to `tools/adb/shots/phase5-*.png` (git-ignored; they show generated lab photos, never a real hand).

<objective>

Purpose: ROADMAP Phase 5 success criteria 1-5 as one end-to-end check before `/gsd-verify-work`.
Output: tools/result-walk.sh, the phase5 screenshots (local), the updated 05-VALIDATION.md, the phase summary with the phone-session list.
</objective>

Read the expected strings for en and hi from res/values{,-hi}/strings_result.xml (result_title, invalid_title, each invalid_<reason>_title, result_tab_love, result_tab_career) through tools/res_pattern.py, run as `python -I tools/res_pattern.py XML KEY...`. The helper, so that its output works as a `ui.sh expect` argument on this Windows host: calls sys.stdout.reconfigure(encoding="utf-8") first (Python 3.14 writes cp1252 to a pipe and `-I` ignores PYTHONUTF8, so printing Devanagari fails without it; tools/adb/ui.py does the same); parses the file with xml.etree.ElementTree.parse (reads the bytes, honours the UTF-8 declaration); undoes the Android escapes in each value (backslash-apostrophe to an apostrophe, backslash-quote to a quote, backslash-n to a space because ui.py folds newlines into spaces, backslash-at to @); prints re.escape(value), one line per key in argument order (so brackets such as [Guide] and dots match literally); exits non-zero naming the key when a key is missing. Load the patterns once per language into bash variables.
2. For LANG in en then hi (switch with `cmd locale set-app-locales $PKG --locales $LANG`): for each of the 14 variant codes, run result-open.sh with that variant, the aspect cycling 3:4, 1:1, 9:16 and the skin alternating light, dark, so every aspect meets both tones; expect result_title for valid codes, or invalid_title plus that reason's title for invalid codes; save `phase5-$LANG-$CODE` with tools/adb/shot.sh. For mixed also scroll to and tap the Love and Career tabs and save `phase5-$LANG-mixed-love` and `-career`.
3. Font scale 2.0 (`settings put system font_scale 2.0`, then back to 1.0 inside the loop's own cleanup): in en and hi, open mixed, long_text and invalid_jewelry and save `phase5-$LANG-$CODE-fs2`; then open Home and save `phase5-$LANG-home-fs2` with the last-reading card visible.

5. Share: on the opened reading `ui.sh scroll-to` and tap Share, expect the chooser activity, save `phase5-share-sheet`, press Back.
